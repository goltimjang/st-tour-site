# 상품 올리는 법

상품은 `src/data/products.ts` 파일 하나만 고치면 됩니다.

## 1. 썸네일 준비 (1:1 정사각형)

- 정사각형으로 잘라서 `public/products/` 폴더에 넣습니다. 파일명은 영문으로 (예: `danang-3n5d.jpg`)
- 권장 크기 800×800, JPG. 정사각형이 아니어도 화면에서는 가운데를 잘라 보여주지만, 미리 잘라두면 원하는 구도로 보입니다.

## 2. 상품 정보 추가

`src/data/products.ts` 를 열고 `export const products: Product[] = [` 바로 아래에 항목을 하나 붙여넣습니다.
**맨 위에 넣은 상품이 목록 맨 앞에 나옵니다** (같은 날짜일 때).

```ts
  {
    slug: "danang-3n5d",                      // 주소가 됩니다: /products/danang-3n5d
    title: "다낭 3박 5일 골프패키지",
    summary: "바나힐스·몽고메리 링크스 54홀. 5성 호텔 3박, 왕복 항공 포함.",
    thumb: "/products/danang-3n5d.jpg",       // 1번에서 넣은 파일 경로
    country: "베트남",
    kind: "해외",                              // "국내" 또는 "해외"
    duration: "3박 5일",
    price: "890,000원",                        // 정해지지 않았으면 "견적 문의"
    priceOriginal: "1,090,000원",              // 할인 전 가격 (없으면 이 줄 삭제)
    priceNote: "1인 · 2인 1실 · 항공 포함",
    date: "2026.11.10(화) ~ 11.14(토)",         // 없으면 이 줄 삭제
    badge: "모집 중",                           // 없으면 이 줄 삭제
    highlights: [                              // 상단 요약 박스 (4개 권장)
      { label: "일정", value: "3박 5일" },
      { label: "라운드", value: "54홀" },
      { label: "숙박", value: "5성 호텔" },
      { label: "예약금", value: "30만원" },
    ],
    itinerary: [
      { day: "1일차", plan: "인천 출발 → 다낭 도착 → 호텔 체크인" },
      { day: "2일차", plan: "바나힐스 골프클럽 18홀" },
    ],
    includes: ["왕복 항공료", "호텔 3박", "그린피 3회", "카트비·캐디피"],
    excludes: ["캐디팁", "선택관광", "개인 경비"],
    body: [
      "첫 번째 문단입니다.",
      "두 번째 문단입니다.",
    ],
    published: true,                           // false로 두면 사이트에 안 보입니다
    postedAt: "2026-09-01",                    // 등록일 (최근 날짜가 위로 옵니다)
  },
```

**필요 없는 항목은 그 줄을 통째로 지우면 됩니다.** 꼭 있어야 하는 것은
`slug`, `title`, `summary`, `thumb`, `country`, `kind`, `duration`, `price`, `published`, `postedAt` 입니다.

## 3. 반영

파일을 저장하고 커밋·푸시하면 몇 분 뒤 사이트에 자동으로 올라갑니다.

```bash
git add -A && git commit -m "상품 추가: 다낭 3박 5일" && git push
```

## 주의할 점

- `slug`는 상품마다 **겹치지 않게** 하세요. 이미 쓴 slug를 다시 쓰면 오류가 납니다.
- `published: false` 로 바꾸면 목록과 상세에서 모두 사라집니다. 지우지 않고 잠시 내릴 때 쓰세요.
- 콤마(`,`)와 따옴표(`"`)를 빠뜨리면 사이트 빌드가 실패합니다. 기존 항목을 복사해서 내용만 바꾸는 것이 가장 안전합니다.
