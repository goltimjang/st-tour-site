# 메뉴 잔류 버그 및 주요 기능 점검

## 원인과 수정
- 운영 PC 화면에서 맞춤 골프여행 클릭 후 마우스를 본문으로 옮겨도 하위 메뉴가 남았고 Esc도 닫지 못했다. CSS group-focus-within이 페이지 이동 후 남은 링크 포커스를 계속 열림으로 처리했다.
- Header에서 명시적 열림 상태를 사용한다. 상위 링크는 이동, 옆 화살표는 열기/닫기로 구분. 마우스 호버, 키보드 버튼 및 ArrowDown 탐색 지원.
- 링크 선택(같은 경로 포함), 바깥 클릭, 포커스 이탈, Esc, 경로/해시/뒤로가기, PC·모바일 경계 전환 시 닫는다. Esc는 메뉴 버튼으로 포커스 복귀하며 키보드 포커스 표시는 유지.
- 모바일 로고·외부 상담 링크도 메뉴를 닫는다. 검색 열기 시 모바일/PC 메뉴를 닫아 중첩 방지. 검색 닫힘의 포커스 복귀에 preventScroll 적용.

## 검증 결과
- 운영 원인 재현 후 로컬 정적 빌드에서 같은 경로 클릭, 다른 하위 링크 선택, 호버 열기, 바깥 클릭, ArrowDown/ Esc 및 포커스 복귀 통과.
- 모바일 메뉴 열기/닫기, Esc, 바깥 클릭, 홈 로고, 검색 열기, 페이지 이동, 뒤로가기, 화면 크기 전환 후 닫힘 확인.
- 검색 '포세븐' 결과에서 할인부킹 이동, 검색 모달 닫힘 및 body 스크롤 복구 확인.
- 홈 팝업 Esc 닫기 및 같은 세션 재방문 비노출 확인.
- 홈 베트남/하노이/미정 → 견적 전달, 국가 변경 시 기존 지역 초기화, 10/20~10/24의 4박 5일 계산, 항공 출발 시간 전달, 연락처 단계 왕복 시 입력 보존 확인.
- 상품 국가/지역 필터, 국가 변경 시 지역 초기화, 결과 0건, 전체 초기화, 포함·별도 비용 탭, 호텔 사진 전환, 저장/해제, 상품 문의 앵커 확인.
- 할인부킹 빈 필드 검증, 단체 10팀 선택 및 3인 전환 후 팀 수 초기화 확인.
- 할인부킹 브라우저 fetch를 로컬 응답으로 대체하여 503 실패 → 입력 보존 → 성공 재시도 확인. 동일 접수번호 유지와 단체 10팀 payload/결과 화면 확인. Formspree 실제 네트워크 호출 및 메일 발송 없음. 페이지 이동으로 테스트 대체 함수 해제.
- 320/375/1280px에서 홈·해외 견적·할인부킹·상품 상세 총 12개 조합 가로 넘침 없음. 초기 홈 이미지 로딩 중 항목은 후속 조회에서 로드 확인. 화면 밖 이미지는 lazy loading이므로 미로드를 오류로 판정하지 않음.
- 브라우저 앱 오류 없음. 로컬 반복 빌드 후 캐시된 상품 페이지가 초기화되지 않는 현상은 캐시 없이 새로고침 후 갤러리/메뉴 정상화 확인. 운영 동일 오류로 단정하지 않음.
- npm run build, 오프라인 전송 16개 및 할인부킹 41개 검사, 110페이지 정적 검사, 76개 공급 상품 검사, 288개 상품 사진 배치 검사, git diff --check 통과.

## 범위 한계
- 실제 고객 문의, 메일 수신, 카카오 알림톡, 결제·예약 확정은 실행하지 않았다.
- 모든 브라우저/실기기/네트워크 상태에서 오류가 없음을 보장하는 검사가 아니다. 주요 사용자 동선 및 정적 전체 페이지 검증 범위다.
