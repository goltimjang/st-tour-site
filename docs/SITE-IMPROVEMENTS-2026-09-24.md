- 상품 저장·저장 해제·저장 목록·공개 상품 링크 복사·기기 공유 기능을 추가했다. 저장은 현재 브라우저에 상품 ID만 보관한다. 개인 견적·연락처는 저장하거나 공유하지 않는다.
- 상품 상세의 모바일 하단 무료 견적 버튼이 해당 상품 견적으로 연결되도록 수정했다.
- manifest에 앱 이름·기존 512px 아이콘·standalone 실행·저장 상품 바로가기를 추가했다. 앱스토어 출시 또는 오프라인 구현 완료라는 뜻은 아니다.
- 사이트 수정일·llms.txt·인수인계 문서를 갱신하고, 호스팅 및 고객 견적 서버 연결 계획을 별도 문서로 작성했다.
