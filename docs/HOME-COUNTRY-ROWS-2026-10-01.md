# 국가별 홈 상품 슬라이드

## 디자인 계획
- 사용자 정정: 혼합 국가 한 줄 대신 베트남, 태국, 일본, 중국, 필리핀 순서로 각각 한 줄. 국가별 대표 상품 3개가 오른쪽으로 순환한다. 베트남 첫 상품은 로얄CC 행사다.
- 색상: 기존 Navy #06143e, Royal #0d4ff5, Green #0f3c32, Paper #f7f8f5, White #ffffff 유지.
- 글꼴: 국가 제목 GmarketSans, 상품 정보/버튼 Pretendard. 기존 히어로는 유지.
- 배치: 국가 제목과 전체 보기 / 사진 중심 상품 3열 / 재생·방향 조작. 모바일은 카드 한 장과 다음 장의 일부, 손가락 드래그.
- 상품 선택: 국가마다 서로 다른 지역을 우선하며 확인된 사진과 기존 상세 링크만 재사용. 새 가격·시설 주장을 만들지 않는다.
- 검토: 국가를 섞거나 무한히 빠르게 흘리는 장식 대신, 한 줄씩 독립적으로 5초 읽기 시간을 두고 이동. 화면 밖·마우스·포커스·드래그·팝업·탭 숨김 시 정지. 모션 감소 설정 존중.

## 적용 자료
- GitHub Anthropic frontend-design 스킬: https://github.com/anthropics/skills/tree/main/skills/frontend-design (사용자 요청으로 설치·읽고 적용).
- Embla Carousel React 8.6.0: https://www.embla-carousel.com/docs/v8/get-started/react
- 자동 이동은 scrollPrev로 카드가 물리적으로 오른쪽으로 움직이도록 한다. 순환용 두 번째 묶음은 별도 상품이 아니며 보이지 않는 카드는 접근성 탐색에서 제외한다.

## 검증
- 빌드, 110페이지 정적 검증, 76개 공급 상품, 288개 사진 배치, 견적 전송 16개/부킹 입력 41개 오프라인 검사 통과. 금지어/엠대시 및 diff 공백 검사 통과.
- Chrome 1280/1440px에서 3열, 320/375px에서 가로 넘침 없이 카드/44px 방향 버튼 표시. 320px에서는 장식 점을 숨겨 정지 버튼 글자를 한 줄로 유지.
- 5개 국가 각각 7초 관찰로 자동 순환 확인. 이동 중 translate 값이 증가해 카드가 오른쪽으로 이동함을 확인. 3개를 반복하는 경계에서도 빈 공간 없이 순환.
- 오른쪽/왼쪽 수동 버튼, 일시정지 6.2초 유지, 호버 6.2초 유지, 모션 감소 자동 정지 및 수동 버튼 작동 확인.
- 브라우저 터치 에뮬레이션으로 가로 스와이프 확인. 실물 휴대전화 점검은 미실시.
- 상품 이미지 로딩과 로얄CC 카드에서 실제 행사 상세 연결 확인. 기존 접수 코드는 수정하지 않았고 실제 문의도 발송하지 않음.
- npm 설치는 Embla 3개 패키지만 lockfile에 추가. 기존 Next/sharp 보안 알림은 이번 변경에서 발생한 것이 아니며 별도 의존성 갱신 검토 대상.
