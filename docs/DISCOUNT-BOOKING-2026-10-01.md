## 알림톡 후속 준비
자동 발송은 **미연결**. 폼 성공 화면에 카카오 수신을 약속하지 않음. 접수번호/문의유형/상품코드로 후속 서버 작업 분기 가능.
1. 접수 저장 확인을 선행한다. 브라우저에서 직접 카카오 발송 키를 사용하지 않는다.
2. 할인부킹 접수 안내 템플릿은 문의 접수와 예약 미확정을 명확히 구분한다.
3. 할인 금액 안내는 담당자가 가능 여부·포함/별도 비용·유효기한을 확인한 뒤 발송한다.
4. 예약 확정은 별도 확정 처리 뒤 별도 알림. 알림 실패는 재시도하되 접수 내용을 다시 생성하지 않는다.
5. 준비 완료 후 본인 시험 번호로 별도 승인된 발송 테스트를 진행한다.
