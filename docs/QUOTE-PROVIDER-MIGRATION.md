# 견적 접수 서비스 전환 준비

작성: 2026-09-30

## 현재 상태

FormSubmit 운영 전송 장애 때문에 Formspree 연결을 준비했다. 새 계정/폼 ID 미확보 상태이며 **운영 전환과 실제 수신 확인은 아직 완료되지 않았다.**

## 선택한 방식

- 기존 견적 화면 → Formspree 접수 관리 화면 저장 및 담당자 이메일 알림.
- 수신자: 기존 운영 메일 goltimjang@gmail.com. 다른 광고주/고객의 계정은 사용하지 않는다.
- 공식 요금 안내 확인일 2026-09-30: 무료 월 50건, 접수 기록 30일. 테스트 요청도 한도를 사용할 수 있다. 자동 유료 전환/결제는 하지 않는다.
- 영구 보관용 자체 DB가 아니다. 이메일 알림과 대시보드 접수 확인을 별개로 검증한다.

## 준비한 코드

- `src/lib/quote-delivery.ts`: Formspree 공개 폼 ID 설정 시 새 서비스만 사용. 메일은 선택이며 제목과 전체 여행 조건을 전달한다.
- 실패 시 다른 서비스로 자동 재전송하지 않는다. 중복 접수와 이중 개인정보 전달을 피한다.
- 성공 JSON을 확인해야 완료 화면으로 이동. HTML, 인증/봇 검증, 한도 초과, 서버 오류, 통신 단절은 기존 복사/카카오톡/메일/전화 복구 화면을 유지한다.
- ID 미설정 시 현재 배포된 FormSubmit 경로 유지. 실제 ID/계정 확인 전 이 준비 변경은 배포하지 않는다.
- GitHub Actions 변수 `NEXT_PUBLIC_FORMSPREE_FORM_ID`에는 공개 폼 ID만 넣는다. 관리 API 키나 비밀번호를 넣지 않는다. 정적 사이트이므로 변수 변경 후 재빌드 필요.

## 계정 연결 후 반드시 완료할 작업

1. 사용자 소유 계정 가입/로그인과 수신 메일 확인. 비밀번호 입력/약관 동의는 사용자에게 넘긴다.
2. 에스티골프투어 전용 폼 생성, 수신자와 무료 플랜 확인, 공개 폼 ID 확보.
3. 현재 폼의 스팸/캡차 설정 확인. 추가 인증이 요구되면 해당 인증 UI를 연결한다. 인증을 임의로 해제하거나 실패를 성공으로 취급하지 않는다.
4. Formspree의 실제 보관/처리 정보에 맞게 개인정보처리방침과 동의 안내에 수탁 처리 내용을 반영한다.
5. 배포 전 실제 점검 데이터 1건으로 Formspree 저장과 Gmail 도착 모두 확인. 테스트 이름, 무효 전화번호, '실제 상담 아님' 표시 사용. 실제 고객 자료를 재전송하지 않는다.
6. 국내/해외/상품/페스티벌의 여행 조건, 이메일 미입력, 성공·실패 UI 확인 후 공개 ID 등록 및 빌드/배포.
7. 운영 사이트에서도 실제 접수 번호를 대조하여 저장과 Gmail 수신 확인. 월 사용량을 관리 화면에서 확인한다. 자동 모니터링은 설정하지 않았다.
