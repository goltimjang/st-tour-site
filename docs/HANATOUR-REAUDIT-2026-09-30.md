# 하나투어 상품 원문·사진 재검증 및 견적 편의 개선

## 확인 범위

2026-09-30, 게시 중인 공급 상품 76개의 정확한 개별 출발일 URL을 브라우저로 다시 열었다. 상품코드, 상품명, 포함/불포함/선택경비, 펼친 일자별 일정, 시설 카드의 제목과 이미지 URL을 저장했다. 과거 자료만 재사용한 검증이 아니다.

- 원본 기록: `data/imports/hanatour-details-2026-09-30/`
- 사진별 시설·상품 연결: `data/imports/hanatour-photo-curation-2026-09-30.json`
- 사진의 육안 제외 기록: `data/imports/hanatour-photo-review-2026-09-30.json`
- 재생성: `scripts/import-hanatour-details.py`
- 회귀 검사: `scripts/check-catalog.py`

원본 자체의 내용 정확성이나 희망 출발일의 판매 가능성을 보증하지 않는다. 표시 일정은 특정 출발일의 대표 예시이며 최종 조건은 견적에서 확인한다. 항공 제외 가격이 분리 확인되지 않은 상품은 계속 '견적 문의'이다. 기존 4개 항공 불포함 상품의 숫자 참고가는 별도의 가격 확인일을 유지한다.

## 발견·수정한 불일치

- 가족 상품의 여러 여행기간과 단일 상세 일정이 혼재: 공개 제목·기간을 확인한 상세 일정의 일수와 일치시켰다. 총 46개 제목이 기간 또는 명칭 변경 대상이다. 다른 기간은 상세 조건/상담에서 요청할 수 있다.
- 샤먼 준5성 표기 → 원본의 준특급. 하이난 미란·고염전 묶음 → 확인한 고염전 상세. 칭다오 제목의 미확인 천태 제외.
- 로알센트럴/인타프리/도조노모리 표기를 로얄센트럴/인다푸리/토조노모리로 정리. 치앙마이 알파인 상품의 하이랜드 단정 제거.
- 고베 아리마 제목과 일자별 후루츠플라워 호텔이 다름: 실제 일정 숙소명으로 정리.
- 소노펠리체 하이퐁 상품 원문에 옌바이·르블랑 내용과 해시태그가 섞여 있음: 일자별 소노펠리체 시설 카드·사진을 사용. 다른 지역 문구를 광고성 설명으로 복사하지 않음.
- 옌바이 객실 인원 조건이 원문 내 상충: 객실 인원 확정 안내 제거, 견적 확인으로 표시.
- 칸차나부리 원문 숙소 목록에 파타야 타이시암 혼입: 해당 숙소를 제외하고 허니퀸 조건 재확인 안내.
- 항공권과 차량 안내가 같은 문단인 고베 등에서 문단 전체 삭제로 차량이 누락됨: 항공 항목만 제거하여 차량 조건 복원.
- 식사로 기내숙박·숙박 없음이 표시되던 선택자 오류와 중복 식사 표기 제거.
- 선택경비를 필수 불포함 비용에서 분리하고 긴 세부 조건은 펼쳐보기로 제공.
- 가산 골프챌린지와 2027 디오픈은 행사 출발일을 명시하고 다른 날짜는 같은 행사 구성이 아님을 안내.

## 사진

기존 상세 갤러리는 487개 고유 파일, 상품별 총 580회 노출이었다. 재검증 후 344개 고유 사진, 총 390회 노출로 변경했다. 기존 고유 사진 중 263개를 갤러리에서 제외하고, 해당 일정의 시설 카드에서 확인한 120개로 교체·보완했다. 344개 전체를 연락시트로 육안 확인했다. 원본 이미지 자체의 촬영 장소를 별도로 현장 인증한 것은 아니다.

공항, 출입국·미팅 안내, 쇼핑·관광 추천, 지도/안내판, 화장실, 옷장, 인물 중심 사진, 중복 장면 등을 제외했다. 실제 이용 예정인 공항 인근 호텔의 시설 사진은 공항 사진과 구분했다. 모든 사진은 같은 상품의 원본 시설 카드에 속하는지 검사한다. 서로 다른 국가에 동일 사진이 배정된 사례는 없다.

대표 썸네일도 해당 상품의 검증된 갤러리 사진으로 연결했다. 사용하지 않는 상세 이미지 파일 279개를 정리했다(이 수에는 이번 다운로드 후 제외된 파일도 포함).

## 구성 가능 여부 확인이 필요한 4개 상품

원본에 `현지합류(불가)` 표기가 있는 보르네오CC, 파타야 타이시암 파크골프, 칸차나부리 허니퀸, 치앙마이 제키파크골프는 목록·상세·견적 폼에 항공 제외 구성 확인 필요를 표시한다. 해당 경고를 접수 payload에도 전달한다. 문의 접수는 확정 예약이 아니다.

## 고객 동선과 검증

- 모바일 상세 일정이 폼보다 먼저 나온다. 기존 하단 고정 상담바는 '이 상품 견적 요청'으로 연결한다.
- 상단 시설 사진 넘기기/썸네일, 일차별 코스 요약, 포함/별도/선택 비용 구분.
- 날짜 미정과 대략적인 희망 시기 선택 지원. 선택한 상품 제목을 첫 단계와 최종 확인에 유지.
- 320/375/768/1440px 가로 넘침 검사, 320px 갤러리 버튼 너비 및 375px 견적 화면 육안 확인.
- 실제 이메일 릴레이가 제거된 별도 로컬 서버에서 2회 모의 접수. 옌바이 '1~2개월 안에·5명' 및 허니퀸 '2026-11-14·4명'의 상품코드/조건/항공 불포함/구성 확인 사항 전달 확인.
- 실제 문의를 발송하지 않았다. 실수신이나 유효 문의 성과를 검증했다고 주장하지 않는다.
- 빌드·108개 정적 페이지·76개 원본-사진 연결 검사 통과.
