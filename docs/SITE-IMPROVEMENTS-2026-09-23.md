# 사이트 개선 기록 · 2026-09-23

## 반영한 변경

- 첫 화면을 밝은 배경과 짧은 안내, 무료 견적·전화 CTA로 재구성했다. 일정이나 지역이 미정인 고객도 견적을 시작할 수 있다.
- 하노이 프로모션, 여행지 선택, 진행 절차, 실제 행사 사진, 견적서 예시, FAQ 순서로 홈을 정리했다. 갤러리는 자동 이동 대신 고객이 직접 넘긴다.
- 작은 모바일과 태블릿의 헤더 넘침을 수정하고 1280px 미만에서 접힌 메뉴를 쓴다. 하단에는 전화·무료 견적 두 버튼을 제공하며 폼 입력에 집중할 때 숨긴다.
- 견적은 기본 여행 조건에서 연락처로 바로 이동한다. 숙박·항공·예산·골프장은 선택 입력이다. 제출 전 지역·일정·인원·골프장을 확인할 수 있다.
- 국가·상품별로 초안을 분리하고 7일간 여행 조건만 저장한다. 성함·전화·이메일·메모는 새 초안에 저장하지 않는다. 다른 국가의 조건이나 담은 골프장이 자동으로 섞이지 않도록 했다.
- 하노이 전용 견적 폼에 상품·국가·여행일·3박5일·골프장을 연결했다. 주요 별도 비용과 예약 전 확인 사항을 가격 가까이 배치했다.
- FormSubmit의 HTTP 상태와 성공 응답 본문을 함께 확인한다. 응답 실패·시간 초과에 오류를 표시하고, 전송 중 중복 실행을 막는다. 확인되지 않은 고객 자동회신 발송 안내는 제거했다.
- 필드 label, 선택 상태, 키보드 포커스, 본문 바로가기, 필수 정보 검증을 보완했다.
- 확인되지 않은 경쟁사 시작가·일반 가격 범위와 확정 회신 시간 표현을 제거했다. 24시간 접수와 실제 상담시간을 구분했다.
- 하노이 상품 데이터를 공통화하고 정적 실적 숫자, 페이지별 구조화 데이터, 본문 FAQ, 수정일, 사이트맵, llms.txt를 정리했다. 사업 실적은 기존 사용자 제공 자체 집계이며 새 증빙을 확인했다는 뜻은 아니다.
- 전화 클릭, 견적 시작·단계·접수 성공·오류를 구분하는 이벤트를 구현했다. 개인정보는 이벤트에 넣지 않는다.

## 외부 확인이 필요한 항목

1. GA4 측정 ID가 아직 없다. GitHub Actions 저장소 변수 `NEXT_PUBLIC_GA4_ID`에 해당 사이트의 `G-...`를 넣고 재배포한 뒤 수집을 확인한다. ID가 없으면 외부 분석 수집 스크립트는 로드되지 않는다. 네이버 광고 전환 코드는 별도 미연결이다.
2. 실제 문의 전송은 사용자 승인이 없으므로 하지 않았다. 승인 후 운영자 메일 수신·스팸함·접수번호 대조를 확인해야 한다. 로컬 모의 성공은 실제 메일 도착 증거가 아니다.
3. 전화 클릭은 통화 연결이나 유효 상담·예약이 아니다. 유효 문의는 지역·시기·인원 등 상담 가능한 정보를 확인한 상담 기록과 연결해 평가한다.
4. 검색엔진의 재수집·검색 요약 갱신은 네이버 서치어드바이저와 Google Search Console 소유 계정에서 확인해야 한다. 코드 정리가 순위 또는 AI 답변 인용을 보장하지 않는다.
5. 사업 실적의 집계 자료, 등록번호, 최신 운영 사례·후기는 실제 자료가 제공되면 반영한다. 검증 자료를 새로 만들거나 추정하지 않는다.
